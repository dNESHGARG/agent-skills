# Agent Skills

Reusable, evidence-first engineering workflows for coding assistants.

## Skills

- [Code review](skills/code-review/SKILL.md) — correctness-focused reviews with reproducible findings.
- [Bug investigation](skills/bug-investigation/SKILL.md) — narrow down symptoms, isolate causes, and verify fixes.
- [Concurrency audit](skills/concurrency-audit/SKILL.md) — identify races, deadlocks, cancellation issues, and ordering hazards.

Each skill can be adopted independently. Review outputs are advisory; run the tests and inspect the code yourself.
